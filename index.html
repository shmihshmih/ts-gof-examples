Как различать похожие паттерны

Factory Method и Abstract Factory
Factory Method отдаёт выбор отдельного продукта подклассу. Abstract Factory выдаёт набор совместимых продуктов через один интерфейс.
Builder и Template Method
Builder отделяет общие шаги создания от представления результата. Template Method фиксирует порядок алгоритма в базовом классе и позволяет подклассам переопределять его шаги.
Adapter, Decorator и Proxy
Adapter переводит между интерфейсами. Decorator добавляет поведение и сохраняет интерфейс. Proxy сохраняет интерфейс и управляет доступом к объекту.
State и Strategy
State связывает поведение с текущим этапом и его переходами. Strategy отдаёт выбор алгоритма клиенту.
Observer и Mediator
Observer рассылает событие подписчикам. Mediator ведёт взаимодействие участников по правилам.
Command и Memento
Command представляет действие. Memento хранит состояние. В истории действий команда может использовать снимок для отмены.
